# M8 / BUILD — інтерактивна майстерня

Український вебпосібник зі складання M8 Headless: BOM, БД цін UA ↔ AliExpress, дев’ять етапів, інтерактивна 3D-концепція корпусу, справжні скріншоти, тренажер клавіш і журнал перевірок.

## Запуск

Потрібен Node.js 22.12+ (перевірено на 24.18).

```sh
npm ci
npm run dev
```

Відкрити адресу, яку покаже Vite (зазвичай http://127.0.0.1:5173).

```sh
npm run build
npm run preview
npm test
npm run test:e2e
```

Для E2E один раз встановити браузер: `npx playwright install chromium`.
Продакшн-артефакт — `dist/`; навігація використовує hash, тому серверні rewrite не потрібні. Для розміщення у підпапці потрібно налаштувати base та абсолютні посилання public assets. Поточна конфігурація розрахована на корінь домену.

## Основний клієнт

На явний запит користувача **клоновано саме [laamaa/m8c](https://github.com/laamaa/m8c)** як git submodule у `upstream/m8c`. Зафіксовано **v2.2.3**, commit `dbf61664f46c73c66552ace2ef71e8311d743125`. Його код не змінювався.

Після клонування цього репозиторію:

```sh
git submodule update --init --recursive
```

Вебпосібник і C-клієнт — різні програми. npm збирає посібник; `make` у submodule збирає клієнт за його платформною інструкцією. C-клієнт потребує SDL3 та libserialport. На цьому Windows-ПК клієнт не компілювали та Teensy не прошивали.

## Прийняті уточнення

- Pi Zero 2 W **виключено** за прямим уточненням користувача.
- Зовнішній орієнтир — [Dirtywave M8 Model:02](https://dirtywave.com/cdn/shop/files/M8-Model02-Front1.jpg?v=1707060425).
- Raspberry Pi 4 — **кандидат хоста**, обґрунтований наявною апаратною збіркою RowdyVoyeur. Її старий SDL2-fork/образ не підміняють обраний laamaa/m8c.
- Корпус у 3D — оригінальна **навчальна концепція**, а не готовий до виробництва CAD. Геометрія модулів схематична. Точний дисплей, HID-контролер, кріплення та повний Linux-образ ще відкриті.
- BOM має статуси та порожні ціни замість вигаданих пропозицій. Бюджет рахується за введеними користувачем цінами в UAH, окремо від доставки.
- БД цін порівнює канали UA / AliExpress / виробник і прив’язана до BOM за id позиції. Діапазони в ній — **орієнтир ринку на дату `pricedAt`, а не котирування продавця**: підтверджена ціна з’являється лише тоді, коли користувач вписав її сам. Мито, доставка й комісії в діапазони не входять.
- Жодної апаратної перевірки не позначено виконаною. Чекбокси — записи самого користувача.

## Дані й матеріали

- `src/data.js` — єдине джерело етапів, BOM і посилань.
- `src/vendors.js` — БД цін: вендори, канали постачання, орієнтовні діапазони та пошукові запити, прив’язані до id позицій BOM. `docs/prices.md` і `public/docs/prices.json` генеруються з нього.
- `src/model.js` — Three.js-модель; `public/cad/m8-concept.scad` — редагована концепція OpenSCAD. STL доступний у вебпереглядачі, лише для візуалізації.
- `docs/` — дослідження, рішення, setup та критерії перевірок.
- `public/media/` — оригінальні скріншоти Dirtywave/M8Docs; походження та ліцензія в `THIRD_PARTY_NOTICES.md`.
- `scripts/generate-docs.mjs` — генерує BOM, setup і БД цін з тих самих даних, копіює документацію в public. Виконувати після зміни контенту.
- `scripts/diagnose-pi.sh` — read-only діагностика з перевіркою Pi/ARM; не запускається вебсторінкою.
- `readme-utf8-bom.md` — вихідний документ користувача, збережений без змін. Пізніші прямі уточнення користувача мають пріоритет над його попередньою архітектурою.

Прогрес зберігається в localStorage. Для перенесення між браузерами використовуйте JSON export/import. Журнал можна експортувати як `validation.md` і зберегти в `docs/` вручну. Вебдодаток не має доступу до пристроїв чи файлів репозиторію. Google Fonts завантажуються онлайн; при відсутності мережі використовуються системні шрифти.

Цей незалежний посібник не є офіційним продуктом Dirtywave. Підтримайте авторів M8 та m8c.
