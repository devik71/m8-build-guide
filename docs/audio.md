# Аудіо

Цільовий маршрут: Teensy USB Audio → laamaa/m8c v2.2.3 / SDL → фізичний USB-аудіовихід. Спочатку ПК, потім ARM host. F1 → Audio enabled → Save; F12 — перемикання. У v2.2.3 меню не містить вибору пристрою: audio_device_name задається в [audio] config.ini (Default — системний вихід). Файл редагувати із закритим клієнтом. Перевірено за src/settings.c і src/config.c клонованої ревізії. Уникати другого паралельного loopback.

Фіксувати sample rate, buffer, модель інтерфейсу, ОС, версію SDL3, умови живлення й навантаження. Перевірити лівий і правий канали окремо. 30 хвилин відтворення з семплами; записати xruns/тріск, температуру і throttling. Відсутність звуку на Pi перевіряти окремо від наявності картинки.

Для навушників потрібен вихід, розрахований на навантаження навушників; назва DAC цього не гарантує. Для мікшера — стерео TRS на два відповідних канали, не один balanced mono-вхід.

Точний USB-модуль ще не обрано. HS-100B — лише приклад з апаратного референса. Аналоговий вхід/MIDI не є критеріями MVP. Старий прямий I²S-рецепт rheslip не застосовується.
