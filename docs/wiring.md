# З’єднання стенда

```text
microSD MUSIC → Teensy 4.1
Teensy micro-USB → USB-A Raspberry Pi 4
microSD OS → Raspberry Pi 4
Pi 4 micro-HDMI → HDMI-дисплей
USB HID-контролер → USB-A Pi 4
USB-аудіоінтерфейс → USB-A Pi 4 → стереонавушники
Зовнішнє живлення → USB-C Pi 4
Живлення дисплея → за документацією конкретного модуля
```

Це функціональна схема. Монтажної схеми кнопок ще немає: точний HID-контролер і switch footprint не обрані. Таблицю фізичних контактів/GPIO не фіксуємо, оскільки активний шлях — USB HID, а не GPIO Pi.

Усі перепідключення проводки виконувати зі знятим живленням. Перший Teensy живиться тільки від USB. Не подавати 5 В на сигнальні контакти. Перед увімкненням перевірити відсутність короткого замикання. Не підміняти micro-HDMI Pi 4 кабелем mini-HDMI зі старого плану Zero.

Перевірка кнопок: кожний press/release; Shift+Edit+кожна стрілка; відпускання в різному порядку; тривале утримання; від’єднання контролера без залипання. Записати результати в журнал.
