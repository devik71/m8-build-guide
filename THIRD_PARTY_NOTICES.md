# Походження матеріалів

## laamaa/m8c

Незмінений git submodule `upstream/m8c`, upstream https://github.com/laamaa/m8c, v2.2.3, dbf61664f46c73c66552ace2ef71e8311d743125. MIT для основного коду, додаткові повідомлення та ліцензії компонентів — у власному `LICENSE` upstream. Не поширюємо firmware binary всередині посібника.

## Скріншоти Dirtywave/M8Docs

`public/media/touchdesigner_config.png`, `download_firmware.png`, `diagonal_lines.png` скопійовані без модифікації з:
https://github.com/Dirtywave/M8Docs/tree/3886b348bc1b97818b25fa7348fc6a27775afc90/docs/images

Документація розповсюджується за GPL-2.0; точна копія ліцензії: `public/licenses/M8Docs-GPL-2.0.txt`. Оригінальні PNG є їх вихідною формою. Авторство — учасники Dirtywave/M8Docs. Скріншоти показують історичний TouchDesigner; його keymap не видається за поточний m8c. Посилання на джерело й ліцензію доступні в UI.

## Візуальний референс

Фото Model:02 на dirtywave.com, надане користувачем, використано для візуального аналізу. У public воно не копіювалося: додаток посилається на оригінал. Геометрія Three.js/OpenSCAD і навчальна схема екрана створені для цього посібника; не використовують шрифт M8 чи брендований логотип Dirtywave.

## Корпуси сторонніх авторів

Файли rheslip/M8-Headless не включено: загальної ліцензії репозиторію не виявлено, і цей host виключено користувачем. MakerWorld не вдалося перевірити. Наявність STL онлайн сама по собі не є дозволом на повторне розповсюдження.

Залежності npm та їхні версії зафіксовані в package-lock.json. Їхні ліцензії зберігаються в пакетах.
