# Перевірка вебпосібника

Дата: 2026-09-13. Windows; Node.js 24.18.0; Chromium 153 через Playwright.

- `npm run build`: успішно. 3D завантажується окремим lazy chunk (~591 kB до gzip); Vite повідомляє про розмір цього chunk. Це не помилка збірки.
- `npm test`: 5/5. Очищення імпорту/пошкоджене сховище; точний прогрес; бюджет із кількостями, невідомою/нульовою ціною та наявними деталями; стабільні content IDs.
- `npm run test:e2e`: 6/6. Дев’ять етапів, persistence notes/checklist, BOM та CSV, 3D-розсування/ізоляція/STL, keyboard multi-key і release/blur, мобільне меню/ширина, import/export журналу.
- Переглянуто desktop screenshot 1440 px: overview, 3D-корпус; мобільний layout 390 px. Немає перекриття основних елементів.
- `upstream/m8c` клоновано й зафіксовано v2.2.3. F1/F12 і назви config перевірені безпосередньо в src/config.c та src/settings.c. Меню цієї ревізії не має вибору аудіопристрою: це виправлено в інструкції.

Межі: не компілювали C-клієнт на Windows чи Pi, не прошивали Teensy, не тестували фізичне аудіо/кнопки/батарею. OpenSCAD не рендерився CAD-рушієм; експортується навчальна геометрія, не готовий printable enclosure. Автоматичні браузерні перевірки не доводять сумісності заліза.
