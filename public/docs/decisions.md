# Рішення

1. Основний клієнт — laamaa/m8c. Це пряме уточнення користувача; клон зберігається без змін, v2.2.3, git submodule.
2. Pi Zero 2 W виключено прямим уточненням користувача. Початковий README є історією вимог, не поточною остаточною архітектурою.
3. Pi 4 — запропонований кандидат host за існуючим RowdyVoyeur-проєктом. Наявність плати не підтверджена. Немає обіцянки вмістити її в оригінальні розміри M8.
4. Вигляд наближаємо до наданого Model:02: вертикальний темний корпус, екран угорі, 8 кнопок, розбірна кришка. Немає чужого логотипу чи заяви про офіційність.
5. Власна концепція Three.js/OpenSCAD — для пояснення і компонування. Final print CAD блокується відсутністю конкретного дисплея та HID. Показувати відкриті параметри явно.
6. Аудіо через USB і вбудований routing m8c/SDL, далі фізичний USB-вихід. Не переносимо I²S DAC із застарілих headless-рецептів.
7. Кнопки через USB HID — проєктне рішення на основі референса. Схему пайки видаємо тільки для вибраного контролера після перевірки rollover.
8. Спершу зовнішнє живлення. Батарея після вимірів.
9. Вебпосібник без backend. Власні ціни, checkbox і нотатки зберігаються локально; JSON backup та Markdown/CSV export. Жодні hardware checks не виконуються автоматично.
10. Інструкції, checklist і BOM живуть у src/data.js. Документація генерується звідти, щоб не розходилась із UI.
